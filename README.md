# Student Marks Analyzer Using Python

A Python console application built for **Week 1** of my AI/ML Internship at **Codomax Digital Solutions**. It collects student marks across custom subjects, validates inputs, calculates totals and averages, assigns letter grades, determines pass/fail status, and displays a class performance summary.

## Key Features
- Dynamic input for custom subject names and multiple students
- Input validation to ensure marks stay between 0 and 100
- Automatic calculation of total marks, average percentage, and letter grade
- Subject-wise and overall Pass/Fail evaluation
- End-of-run class summary showing pass/fail count, class average, and top scorer

## Python Concepts Used
- Variables and Data Types (`int`, `float`, `str`, `bool`)
- Lists and Dictionaries
- Conditionals (`if/elif/else`) and Loops (`for`, `while`)
- Functions and Exception Handling (`try/except`)
